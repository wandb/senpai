# Offline Artifact Pack

These fixtures support the workshop when live GitHub, W&B, Weave, Kubernetes, or GPU access is unavailable.

Files:

- `fake-pr-body.md` - anonymized experiment assignment PR.
- `student-result-comment.md` - structured student result handoff.
- `advisor-decision.md` - advisor review decision based on W&B and PR evidence.
- `code-diff.patch` - small illustrative experiment diff.
- `wandb-run-summary.json` - W&B-style run config and summary metrics.
- `weave-trace-excerpt.json` - simplified agent/tool trace excerpt.
- `dry-run-launch-redacted.yaml` - redacted launch output for the Kubernetes lab.
- `failure-mode-snippets.md` - concise failure examples for teaching monitoring, tool contracts, and state drift.

All names, PR numbers, and run IDs are synthetic.
