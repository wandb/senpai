# Workshop Resources

These files support facilitation, take-home review, and no-network fallback delivery.

| File | Use |
| --- | --- |
| `instructor-guide.md` | Timing, presenter script, audience-specific emphasis, and misconceptions. |
| `architecture-checklist.md` | Staff-engineer design review checklist. |
| `legacy-labs.md` | Optional paper/group labs that mirror the runnable notebooks. |
| `optional-live-demo.md` | Safe demo modes for Slidev, live read-only notebooks, and K8s dry-run. |
| `artifact-pack/` | Offline PR, W&B, Weave, dry-run, and failure-mode fixtures. |

Use the runnable notebooks in `workshop/notebooks/` as the primary learning path. Use these resources when teaching, adapting the workshop for a specific audience, or running without live credentials.
