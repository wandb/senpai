# Research Assessor Harness

This is a fresh, non-persistent assessment conversation. It has exactly one
output-only tool: `submit_research_assessment`. It has no terminal, campaign
operations, browser, project skills, subagents, command secrets, or repair
authority. Your typed decision is the only value returned to trusted control
code. Model-authored prose is ignored and can never become an advisor message
or an operational command.
